# Security Policy

## Supported version

The current public Chrome Web Store release is **1.3.2**.

## Reporting a vulnerability

For security vulnerabilities, privacy-sensitive behavior or reports that may contain private user information, email:

**noai.extension@gmail.com**

Please do **not** open a public GitHub issue for sensitive reports.

Useful reports include:

- affected No AI Feed version;
- Chrome/Chromium version and operating system;
- clear reproduction steps;
- expected versus observed behavior;
- security or privacy impact;
- relevant logs or screenshots with personal information removed.

Do not send passwords, authentication cookies, private-message contents or other credentials.

Ordinary non-sensitive bugs and feature requests should use GitHub Issues.
